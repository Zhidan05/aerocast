## Catatan Tambahan
- Format Angka: Tetap menggunakan format lokal (misal: Rp950.000), menggunakan locale `id-ID`.
- Format Tanggal: Menggunakan format `id-ID`.
- Mata Uang: INR tetap menjadi mata uang dasar dari dataset. Estimasi konversi ke IDR tetap dipertahankan seperti logika aslinya.
- Istilah teknis yang umum digunakan (seperti API, seed) dipertahankan atau dijelaskan jika perlu.
